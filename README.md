# 漂流異境

以 AI 協作開發的單人魔幻探索與農場經營網頁遊戲。

- [開啟遊戲](./index.html)
- [遊戲規格書](./spec.md)

## 玩法

從海岸家園開始採集、種田、釣魚、交易及鍛造，完成任務後探索森林、雪原、赤焰龍谷與王都遺跡。包含角色養成、背包倉庫、管家、日夜變化與雙結局。

依畫面提示移動與互動；右鍵拖曳地圖，滾輪調整遠近。音樂與音效可在遊戲內切換。桌面瀏覽器操作優先。

## 執行與存檔

主程式為單一 index.html，內含 CSS、JavaScript 與 Three.js。遊戲進度儲存在當前瀏覽器，提供存檔匯入與匯出。從本機移至網站時，請先匯出本機存檔，再於網站匯入。

## 開發紀錄

透過與 AI 反覆討論，從農場概念擴充為五區冒險，逐次調整導航教學、任務、地區模型、日夜光線、音效與岩岸。規格書區分現有功能和後續規劃。
